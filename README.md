# E94104028_final_project
![final](https://github.com/Naneninonuu/E94104028_final_project/assets/95352835/a38bf6b2-0256-44a3-8749-fd9c27fe398a)

> **NCKU Engineering Science | Capstone Project**
> 本專案為國立成功大學工程科學系課程之期末成果，專注於演算法實踐與模組化程式設計。

---

### 📝 專案背景
本專案代表了在大學期間對於**工程問題解決**與**軟體開發流程**的綜合應用。透過實作複雜的運算邏輯，將工程科學的理論轉化為具體的程式碼實現，並在過程中實踐了良好的物件導向設計 (OOP) 規範。

### 💡 核心目標
* **演算法優化**：針對特定計算任務開發高效能邏輯，確保程式在處理大量數據時的穩定性。
* **模組化架構**：將程式碼拆解為可重用的元件，提升系統的可維護性與可讀性。
* **強健性開發**：實作嚴謹的錯誤處理機制 (Error Handling)，確保各種邊界情況下系統皆能正確運作。

### 🛠️ 技術棧
* **程式語言**：C++ / Python (依專案內容調整)
* **核心技術**：物件導向程式設計 (OOP)、資料結構、演算法開發
* **版本控制**：使用 Git 進行開發流程管理

---

### 🚀 技術亮點 (面試重點)
1. **系統化思維**：成功將工程數學模型轉化為功能完備的軟體介面。
2. **邏輯嚴密度**：在開發過程中考慮了複雜的狀態變化，並利用高效的資料結構優化運算速度。
3. **工程素養**：遵循乾淨程式碼 (Clean Code) 原則，包含清晰的變數命名與邏輯結構，便於他人審閱與協作。
